🌍 GeoBingo

Einmalige Einrichtung

GeoBingo braucht einen Google Maps API-Key, damit Street View funktioniert. Den Key gibt es kostenlos, du musst bei Google aber ein Rechnungskonto hinterlegen.

  1. Öffne die Google Cloud Console und erstelle ein Projekt.
  2. Aktiviere die APIs Maps JavaScript API und Street View Static API.
  3. Erstelle unter „Anmeldedaten“ einen API-Schlüssel und kopiere ihn hier rein.

Der Key wird in config.json neben dem Spiel gespeichert und kann nur direkt am Host-PC gesetzt werden. Details zum Absichern des Keys stehen in der README.
